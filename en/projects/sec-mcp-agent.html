SEC MCP agent

MCP servers over SEC filings and a fraud model, and an agent whose citations are checked against the source.

Decision it supports
Answering questions about financial filings with sources someone can check.
Who uses it
Financial and risk analysts who read 10-K filings.
What an error costs
An invented citation leads to a decision based on a fact that is not in the document.
How it creates value
Every citation is checked against the original passage before the answer goes out. The tools live in reusable MCP servers that any agent or Claude Desktop can use.
Risks and limits
18 of 22 questions right in the seventh run: a small model still misses some multi-step questions.

Problem

Answers about filings are only useful if every claim can be traced to the source, and small models invent sources that look real. Tools are also usually wired into one agent, so nothing else can use them.

Solution

Two MCP servers, one over 10-K filings with BM25 search and one over the fraud model, and a tool-calling agent that answers from them. Every citation is checked against the passage it claims to quote before the answer is returned. The same servers plug into Claude Desktop.

How it works

  • A citation passes only if its quote is found in the retrieved passage, and every number in the answer must appear in a cited passage or the fraud score, with no verdict stated against the model's.
  • Eight evaluation runs on a CPU runner, each failure traced and fixed in the agent or the tools; the evaluation reruns every week.
  • The fraud tool reuses the XGBoost model from the real-time fraud project at a pinned commit.

Results

Measured results, from the repository
17 of 22evaluation questions passed in the eighth run (7 in the first; 18 in the seventh, the difference is run-to-run variance)
21 of 22answers whose numbers and fraud verdict match what the tools returned; the one flagged cites the wrong passage for a true number
71tests, including the servers through the MCP client

Limits

A 3B model still misses some multi-step questions; the evaluation set is small; the answer check is lexical, so a right number can still sit next to the wrong subject.

Stack

MCP Python SDK, Pydantic, Ollama, XGBoost
