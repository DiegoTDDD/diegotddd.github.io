Problem

Agents built on small local models fail in ways unit tests do not see: the model sends arguments the tools reject, a reply never ends, a fix in one place breaks another.

Solution

Versioned datasets recorded from real runs, an offline gate that replays them on every pull request, weekly live runs of both agents traced with OpenTelemetry into a self-hosted Langfuse, and a public dashboard.

How it works

  • Datasets are immutable and versioned with a sha256 manifest.
  • Baselines carry tolerances measured from run-to-run variance.
  • Langfuse runs inside CI with Docker Compose, so tracing is tested end to end.
